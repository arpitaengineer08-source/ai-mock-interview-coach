# Contributing

Thanks for your interest in contributing to AI Mock Interview Coach.

## Getting started
1. Fork and clone the repository.
2. Install the root dependencies with `npm install`.
3. Install client dependencies with `npm install --prefix client`.
4. Follow the README to start the server and client.

## Contribution guidelines
- Preserve the local-first design and deterministic fallback behaviour.
- Do not claim that practice scores predict employability or hiring outcomes.
- Keep API request/response contracts consistent between the client and server.
- Add tests when changing routes, evaluation logic or question selection.
- Never commit API keys, personal interview answers or local environment files.

## Pull requests
Describe the user problem, implementation, validation performed and any UI/API impact. Include screenshots for UI changes where useful.
